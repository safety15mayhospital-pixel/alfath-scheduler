# 🏢 الفتح الذكي (Al-Fath Smart Scheduler)
### النظام الشامل لإدارة المواعيد والعملاء والعمل الميداني لـ "شركة الفتح للأنظمة الذكية"

---

## 🌟 نظرة عامة
نظام ويب متطور وتطبيق تقدمي (PWA) فائق السرعة، صُمم خصيصاً لتلبية متطلبات شركات ومقاولي الأنظمة الأمنية والذكية (كاميرات مراقبة CCTV، شبكات، انتركم، بوابات إلكترونية، وأنظمة إنذار). يجمع النظام بين التقويم الذكي المرن، ذكاء العمل الميداني، حجز العملاء الخارجي المستقل، ومساعد ذكاء اصطناعي صوتي ومصري متصل بنظام الأوامر المباشرة (Function Calling).

---

## 👑 1. الهوية البصرية وتجربة الاستخدام (UI/UX)
- **اللغة والاتجاه:** عربي بالكامل (RTL) بخط عربي حديث وواضح (`Cairo` و `Tajawal`).
- **الثيم الملكي:** أخضر زمردي ملكي (`#047857` / `#064E3B`) ذو فخامة وتباين عالي مريح للعين.
- **التبديل الفوري للأوضاع:** زر في الهيدر للتبديل الفوري بين الوضع الليلي (Dark Mode) والوضع الفاتح (Light Mode).
- **تصميم متجاوب للموبايل أولاً (Mobile-First):** شريط تنقل سفلي سريع وأزرار كبيرة لتسهيل الاستخدام بيد واحدة أثناء القيادة أو في مواقع العمل.
- **تطبيق PWA وتخزين أوفلاين:** قابل للتثبيت على هواتف أندرويد و iOS وأجهزة الكمبيوتر كأيقونة مستقلة، ويعمل في وضع عدم الاتصال (Offline-First) مع التخزين المحلي ومزامنة البيانات تلقائياً.

## 📅 2. الموديولات والوظائف الأساسية

### أ) الجدول الذكي والحرية الكاملة (Smart Calendar):
1. **أربعة عروض متكاملة:**
   - **يومي (Day View):** يعرض جدول اليوم بالساعة مع إبراز فواصل المشاوير ووقت التنقل المحمي وأوقات الفراغ.
   - **أسبوعي (Week View):** توزيع مواعيد أيام الأسبوع الستة ونظرة عامة على الكثافة.
   - **شهري (Month View):** شبكة الشهر ونقاط ملونة بعدد المواعيد لكل يوم.
   - **قائمة مهام (Agenda):** قائمة زمنية سريعة مع أزرار مباشرة للاتصال وواتساب والملاحة.
2. **السحب والإفلات التفاعلي (Drag & Drop):** نقل وتغيير وقت أو يوم أي موعد بلمسة واحدة، مع إظهار نافذة تأكيد وسؤال فوري: *"هل تريد تجهيز رسالة تعديل الموعد للعميل عبر واتساب؟"* وزر إرسال فوري بنقرة واحدة.
3. **تقسيم لوني واضح للأنواع الخمسة:**
   - 🔍 **معاينة:** أزرق (Blue)
   - 🛠️ **تركيب:** أخضر زمردي (Emerald)
   - ⚙️ **صيانة:** برتقالي (Amber)
   - 🤝 **زيارة:** بنفسجي (Purple)
   - 🔒 **موعد خاص:** رمادي داكن سري (لا يظهر نهائياً للعملاء في صفحة الحجز الخارجية).
4. **نظام الأولويات:** (مهم جداً 🔥، عادي، غير مهم، مؤجل).
5. **سلة المؤجلات الذكية (Smart Postponed Drawer):** قائمة جانبية تحفظ المواعيد المؤجلة. وبضغطة زر تقوم خوارزمية ملء الفراغات باقتراح أقرب موعد مؤجل زمنياً وجغرافياً لتسكينه فوراً في الفراغ المتاح.
6. **زر الطوارئ (إغلاق اليوم):** إغلاق حجوزات اليوم للطوارئ، وتحويل المواعيد المتبقية لسلة المؤجلات، وتجهيز رسائل اعتذار جاهزة بنقرة واحدة على واتساب العملاء المتأثرين.

### ب) ذكاء العمل الميداني والتحركات (Field Operations):
- **الملاحة الفورية:** كل موعد يحتوي على العنوان والحي ورابط خرائط Google Maps مع زر "افتح الخريطة الآن" لتشغيل الملاحة فوراً.
- **فاصل المشوار التلقائي (Travel Buffer):** حجز وقت تنقل محمي (45 أو 60 دقيقة) قبل وبعد كل موعد ميداني لمنع تداخل المواعيد.
- **تنبيه تجميع المناطق (Area Batching Alert):** شريط علوي ذكي يكتشف تلقائياً وجود موعدين أو أكثر في نفس الحي (المعادي، التجمع، الشيخ زايد...) لتوفير تكلفة المشوار والوقت.

### ج) صفحة حجز العملاء المستقلة (`/book`):
- صفحة مستقلة باسم وشعار شركة الفتح تفتح للعملاء برابط مباشر بدون تسجيل دخول.
- تعرض الأوقات المتاحة الحقيقية فقط بعد استبعاد المواعيد المحجوزة، المواعيد الخاصة، وفواصل المشوار.
- ثلاث خطوات بسيطة: 1. نوع الخدمة، 2. اليوم والوقت، 3. بيانات العميل وزر GPS لتحديد الموقع تلقائياً.
- خيار تحكم من الإعدادات: (تأكيد فوري تلقائي) أو (طلب معلق للموافقة).

### د) ملف العميل الذكي (Client Smart Card):
- نافذة منبثقة تفاعلية عند النقر على أي موعد تشمل: بيانات العميل، سجل مواعيده السابقة، الملاحظات الفنية (نوع الكاميرات/الأجهزة، عدد النقط، وصف العطل)، خانة رسوم المعاينة أو العربون المدفوع، وأزرار اتصال وواتساب وخريطة بلمسة واحدة.

### هـ) المساعد الذكي جوه التطبيق (AI Assistant):
- يفهم اللهجة المصرية بدقة عبر 3 طرق إدخال:
  1. كتابة نصية عادية.
  2. تسجيل صوتي مباشر (Speech Recognition).
  3. رفع صورة سكرين شوت لمحادثة واتساب لاستخراج الاسم والموعد والبيانات تلقائياً.
- نظام الأوامر الفعلية (Function Calling): يضيف الموعد، يرحل المواعيد، يفحص التضارب ويقترح أوقاتاً بديلة شاغرة، ويلخص جدول اليوم.
- دعم مفتاح Gemini API مع وجود محرك تحليل مصري ذكي مدمج محلياً يعمل بدون إنترنت أو بدون مفتاح API.

### و) المنبهات والتذكيرات (Smart Alarms & Notifications):
- Web Audio API لإنتاج أصوات تنبيهية حقيقية: نغمة هادئة للمواعيد العادية، ومنبه طوارئ قوي متكرر للمهم جداً.
- فحص دوري كل دقيقة في الخلفية وتنبيه بوقت التحرك المسبق قبل الموعد.
- زر إرسال واتساب بضغطة واحدة مع رسائل منسقة باسم الشركة.

## 🚀 3. طرق التشغيل

### الطريقة الأولى: التشغيل المحلي الفوري بنقرة واحدة (ويندوز)
فقط اضغط نقراً مزدوجاً على الملف:
```cmd
تشغيل_البرنامج.bat
```
سيبدأ الخادم المحلي المدمج فائق السرعة تلقائياً وسيفتح المتصفح على:
- لوحة التحكم: `http://localhost:5560/`
- صفحة حجز العملاء: `http://localhost:5560/book`

### الطريقة الثانية: تشغيل Node.js & Express
```bash
npm install
npm start
```

### الطريقة الثالثة: النشر السحابي (Railway / Docker / VPS)
الملفات التالية جاهزة ومرفقة في المشروع:
- `Dockerfile`
- `package.json`
- `server.js`

## 📡 4. نقاط الـ REST API المتوفرة
- `GET /api/appointments`: جلب المواعيد.
- `POST /api/appointments`: إضافة موعد جديد مع ربط العميل وفحص التضارب.
- `PUT /api/appointments`: تعديل موعد (السحب والإفلات أو تغيير الحالة).
- `DELETE /api/appointments`: حذف موعد.
- `GET /api/clients`: جلب قائمة العملاء وسجلاتهم.
- `GET /api/settings` & `POST /api/settings`: جلب وتحديث إعدادات النظام.
- `POST /api/emergency/close-today`: زر الطوارئ لإغلاق اليوم وتوليد رسائل الاعتذار.
- `GET /api/reminders/due`: جلب التذكيرات المستحقة (جاهز للربط ببوابة واتساب في المرحلة الثانية).
- `POST /api/booking`: نقطة الحجز للعملاء من صفحة `/book`.
- `POST /api/ai/command`: نقطة المساعد الذكي وتنفيذ الأوامر.
